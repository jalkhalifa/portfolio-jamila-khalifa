# Portfólio — Jamila Khalifa

Site pessoal desenvolvido para apresentar minha trajetória, habilidades e projetos em desenvolvimento web.

## Projetos apresentados

- **La Graci Bolsas:** catálogo digital responsivo com filtros, WhatsApp, painel administrativo e Supabase.
- **Nat Piercer Tattoo:** portfólio bilíngue desenvolvido com HTML, CSS e JavaScript.

## Tecnologias

HTML, CSS, JavaScript, Supabase, GitHub Pages e Netlify.

## Publicação no GitHub Pages

1. Crie um repositório público chamado `portfolio`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main`, pasta `/root`, e salve.

O endereço será disponibilizado pelo GitHub após a publicação.
